# Market-Research — تحلیل صادرات ایران (۱۴۰۰–۱۴۰۵)

> **مخزن Obsidian Vault** برای استخراج، نرمال‌سازی و تحلیل آمار صادرات ایران از سایت گمرک جمهوری اسلامی ایران در بازه **۶ ساله (۱۴۰۰ تا ۱۴۰۵)**. هدف نهایی: **شناسایی محصولات با روند رو به رشد برای انتخاب صادرات**.

این مخزن یک **Vault استاندارد Obsidian** است که هم به‌عنوان پایگاه دانش و هم به‌عنوان منبع دستورالعمل برای همه agentها (انسان و هوش مصنوعی) استفاده می‌شود. هر agent پیش از شروع کار **باید** فایل‌های پوشه `00-Overview/` و `04-State/STATUS.md` را مطالعه کند تا بداند در کجای مسیر قرار دارد.

## 🎯 هدف پروژه

1. استخراج کامل آمار صادرات ایران در **۶ سال گذشته (۱۴۰۰ تا ۱۴۰۵)** از پایگاه داده گمرک. سال ۱۴۰۵ (سال جاری) partial است.
2. شناسایی کشورهایی که صادرات ایران به آن‌ها در این بازه **افزایشی** بوده است.
3. بررسی تک‌به‌تک **کدهای تعرفه (HS Code)** برای تعیین اینکه هر کدام طی ۶ سال به کدام کشورها افزایش یافته است.
4. **حلقه کامل تحلیل روند روی تمام HS Codeها × تمام کشورها** در ۶ سال.
5. **طبقه‌بندی روند هر جفت به ۷ دسته** (رشد قوی، رشد متوسط، پایدار، نوسانی، کاهشی، نوظهور، محوشده).
6. **رتبه‌بندی محصولات کاندید صادرات** با نمره ترکیبی (CAGR + slope + حجم + تنوع + ثبات - نوسان) — این هدف نهایی پروژه است.
7. تحویل خروجی به دو فرمت:
   - **Obsidian Vault** (این مخزن) — برای مطالعه و پایش توسط agentها.
   - **Excel** — برای مصرف کاربر نهایی.
8. دقت عددی: خطای کل تحلیل **کمتر از 0.0001٪**.

## ⚙️ گردش کار کلی

```
Setup → Scrape(6y) → ETL → Analysis(by-country + by-tariff)
   → Trend-analysis(ALL HS×Country) → Trend-classification
   → Export-candidates-ranking → QA → Export(Excel+Obsidian) → Publish(git)
```

جزئیات هر مرحله در `01-Tasks/_MOC.md` و دستورالعمل اجرایی در `03-Recipes/_MOC.md`.

## 🤝 قراردادهای همکاری agentها

1. **هر agent قبل از شروع** باید `04-State/STATUS.md` را بخواند.
2. **هر agent بعد از پایان کار خود** باید یک سطر به `04-State/progress.md` اضافه کند و در صورت تغییر وضعیت، `STATUS.md` را به‌روزرسانی کند.
3. **هیچ agentی** نباید فایل خارج از ساختار تعریف‌شده ایجاد کند.
4. **نام‌گذاری فایل‌ها**: به‌صورت `kebab-case` و با پیشوند شماره تسک در صورت ارتباط (مثلاً `task-04-by-country.md`).
5. **زبان محتوا**: فارسی برای توضیحات، انگلیسی برای اصطلاحات فنی و نام فیلدها.
6. **دقت عددی**: هر محاسبه‌ای باید با دقت `decimal` (نه float) انجام شود. خطای نهایی < 0.0001٪.
