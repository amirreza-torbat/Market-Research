## نمره‌دهی export_score (وزن‌های Decision-009)

```
export_score = 0.30 * norm(cagr_5y)     # ⚠️ Issue-008: cagr_5y جایگزین cagr_6y
             + 0.20 * norm(slope)
             + 0.20 * norm(mean_recent_3y)
             + 0.10 * norm(n_destinations_active)
             + 0.10 * norm(trend_consistency)
             - 0.10 * norm(cv)
```

## فیلتر کاندیداها (۵,۹۹۳ HS → ۵۷۴ کاندید)

روش **membership** (طبق یافته task-11 — نه dominant_trend):
1. حداقل یک جفت در `strong_growth` / `moderate_growth` / `emerging` → ۱,۰۴۶ HS.
2. `mean_recent_3y_aggregated > 1,000,000 USD` → ۶۱۴ HS.
3. `n_destinations_active >= 3` → **۵۷۴ کاندید**.

## توصیه‌ها (recipe-09 §۷)

- `select`: `export_score > 0.7`. — `monitor`: بین ۰.۴ و ۰.۷. — `investigate`: `< 0.4`.
- ⚠️ نمره‌های واقعی در بازه [-۰.۰۳, ۰.۳۵] فشرده‌اند → همه «investigate»؛ بحث بازکالیبراسیون در [[_executive-ranking]] §۵.
