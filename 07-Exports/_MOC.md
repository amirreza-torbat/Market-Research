## شیت‌های Excel نهایی

1. `Overview` — معرفی پروژه
2. `Data-All` — کل داده نرمال‌شده (نمونه)
3. `By-Country-Summary` — خلاصه تحلیل کشورها
4. `By-Country-Top20-Growth` — Top 20 کشور با رشد مطلق
5. `By-Country-Top20-CAGR` — Top 20 کشور با CAGR
6. `By-Tariff-Summary` — خلاصه تحلیل تعرفه‌ها
7. `By-Tariff-Top50` — Top 50 HS Code
8. `By-Tariff-Country` — جدول HS Code × Country (افزایشی)
9. `Charts-Country` — نمودارهای توپ کشورها
10. `Charts-Tariff` — نمودارهای توپ تعرفه‌ها
11. `QA` — خلاصه گزارش QA
