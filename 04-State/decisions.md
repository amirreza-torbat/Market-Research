## Decision-008 — [1405-06-15] trend-taxonomy
**عنوان**: تاکسونومی ۷ دسته‌ای روند.
**تصمیم**: ۷ دسته اصلی + ۳ دسته فرعی:
1. `strong_growth` — CAGR > 10٪، MK p < 0.05، slope > 0
2. `moderate_growth` — 0 < CAGR ≤ 10٪، MK p < 0.1
3. `stable` — |CAGR| ≤ 2٪، R² < 0.3
4. `volatile` — CV > 0.5، R² < 0.3
5. `declining` — CAGR < 0، MK p < 0.1
6. `emerging` — value_start = 0، value_end > threshold
7. `disappearing` — value_start > threshold، value_end ≈ 0
8. `weak_growth` — CAGR > 0 اما بدون معناداری آماری
9. `weak_decline` — CAGR < 0 اما بدون معناداری آماری
10. `insufficient_data` — CAGR قابل محاسبه نیست
**دلیل**: فقط "افزایشی/کاهشی" کافی نیست. کاربر می‌خواهد محصولات با روند رو به رشد انتخاب کند، پس باید بین رشد قوی و ضعیف تمایز قائل شد. نوظهور و محوشده هم مهم‌اند چون فرصت‌ها/خطرهای جدید را نشان می‌دهند.
**تصمیم‌گیرنده**: vault-writer (با تأیید ضمنی کاربر)
**تأثیر**: 
- در `conventions.md` بخش ۵.۱.
- در `task-11` پیاده‌سازی می‌شود.

## Decision-011 — [1405-06-16] customs-url
**عنوان**: منبع داده استخراج (URL گمرک) برای task-01.
**تصمیم**: استخراج از **آینه آمار گمرکی اتاق بازرگانی تهران**: `https://service.tccim.ir/stats`
- Endpoint جزئی: `stats_TarrifCustomCountryDetail_excel?mode=doit&slcImpExp=Export&slcCustom=&slcCountry=&sYear={year}&txtSearchWord={chapter}` (سقف ۵۰ رکوردی view نمایش را دور می‌زند)
- Endpoint تجمیعی: `stats?mode=doit&sYear={year}&slcImpExp=Export&slcCountry=&slcCustom=`
- استراتژی استخراج: حلقه روی ۹۹ فصل HS (کوئری substring) + dedupe کلید رکورد.
**دلیل**: سایت رسمی `tsd.irica.ir` (و کل دامنه `irica.ir`) از خارج ایران **قابل دسترسی نیست** — سه resolver مستقل جهانی (Google, Cloudflare, Alibaba DoH) همگی تأیید کردند که نیم‌سروِ نام‌های دامنه به کوئری‌های خارج از ایران پاسخ نمی‌دهند (Issue-005). آینه tccim همان داده گمرک را ارائه می‌دهد و جمع سالانه آن با آمار شناخته‌شده صادرات ایران همخوانی دارد (۱۴۰۰: ۴۸.۲ میلیارد دلار تا ۱۴۰۳: ۵۷.۸ میلیارد دلار).
**تصمیم‌گیرنده**: scraper (طبق دستور کاربر در پرامپت task-01: «با curl یا مرورگر هر دو را تست کنید... پس از تأیید، آن را در decisions.md ثبت کنید»)
**تأثیر**:
- ساختار فیلدها کمی متفاوت است: رکوردها در سطح تجمیعی (کد تعرفه × ماه × گمرک × کشور) هستند نه اظهارنامه تکی؛ `export_quantity` ارائه نمی‌شود.
- سال‌های ۱۴۰۰-۱۴۰۲ تفکیک ماهانه کامل دارند؛ ۱۴۰۳-۱۴۰۴ رکورد جزئی بدون صفت ماه (Issue-006)؛ ۱۴۰۵ هیچ داده‌ای ندارد (Issue-007).
- اسکریپت: `scripts/scrape_customs.py` (قابل اجرای مجدد برای ۱۴۰۵ پس از انتشار داده در منبع).
