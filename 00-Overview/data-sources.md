# 🌐 منابع داده (Data Sources)

## منبع اصلی (فعلی): آینه آمار گمرکی اتاق بازرگانی تهران

> ✅ **تأیید‌شده در Decision-011** — چون سایت رسمی گمرک از خارج ایران قابل دسترسی نیست (Issue-005).

### منبع فعال: `https://service.tccim.ir/stats`
- **توضیح**: آینه آمار تجارت خارجی گمرک (کشور × گمرک × تعرفه × ماه) منتشرشده توسط اتاق بازرگانی تهران.
- **دسترسی**: رایگان، بدون captcha، بدون ثبت‌نام. `robots.txt` مجاز.
- **Endpoint جزئی** (همه رکوردها — سقف ۵۰ رکوردی view نمایش را دور می‌زند):
  `https://service.tccim.ir/stats_TarrifCustomCountryDetail_excel?mode=doit&slcImpExp=Export&slcCustom=&slcCountry=&sYear={سال}&txtSearchWord={فصل ۲ رقمی}`
- **Endpoint تجمیعی**: `https://service.tccim.ir/stats?mode=doit&sYear={سال}&slcImpExp=Export&slcCountry=&slcCustom=`
- **پوشش**: ۱۴۰۰ تا ۱۴۰۴ (۱۴۰۵ هنوز منتشر نشده — Issue-007).
- **اعتبارسنجی**: جمع سالانه با آمار شناخته‌شده صادرات غیرنفتی ایران همخوان است (۴۵ تا ۵۸ میلیارد دلار؛ جدول QA در `05-Data/raw/_summary.md`).

### کاندید ۱ (مسدود از خارج ایران): درگاه آمار گمرک (TSD)
- **URL**: `https://tsd.irica.ir/`
- **وضعیت**: 🔴 قابل دسترسی از خارج ایران نیست — نیم‌سروِ نام‌های `irica.ir` به کوئری‌های خارج از ایران پاسخ نمی‌دهند (تست‌شده با Google/Cloudflare/Alibaba DoH — Issue-005). اگر از داخل ایران دسترسی دارید، برای اعتبارسنجی متقابل مناسب است.

### کاندید ۲ (پورتال اصلی — همان محدودیت DNS): درگاه اصلی سازمان گمرک
- **URL**: `https://www.irica.gov.ir/`
- **وضعیت**: 🔴 از این محیط قابل دسترسی نیست (همان محدودیت DNS دامنه irica).

### کاندید ۳: درگاه تجارت (Iran Trade Data)
- **URL (کاندید)**: `https://www.irica.gov.ir/portal/home/?report/summary`
- **توضیح**: گزارش‌های آماری فصلی و سالانه.

> ✅ **وضعیت**: منبع فعال (tccim) در Decision-011 ثبت شد. تأیید نهایی TSD (در صورت دسترسی از داخل ایران) همچنان برای اعتبارسنجی متقابل مفید است.

## ساختار داده مورد انتظار از منبع

برای هر رکورد صادراتی به این فیلدها نیاز داریم:

| فیلد (انگلیسی) | نام فارسی | نوع | مثال |
|----------------|-----------|-----|-------|
| `year` | سال شمسی | int | 1405 |
| `month` | ماه شمسی | int (1-12) | 6 |
| `hs_code` | کد تعرفه | string | `"27.09.00.00"` |
| `hs_code_2` | کد ۲ رقمی | string | `"27"` |
| `hs_code_4` | کد ۴ رقمی | string | `"2709"` |
| `hs_description` | شرح کالا | string | `"نفت خام"` |
| `destination_country_iso2` | کد کشور مقصد | string | `"IQ"` |
| `destination_country_fa` | نام کشور مقصد | string | `"عراق"` |
| `export_value_usd` | ارزش دلاری | decimal | 1234567.89 |
| `export_weight_kg` | وزن کیلوگرمی | decimal | 9876543.21 |
| `export_quantity` | تعداد | int | 1000 |

> **نکته سال ۱۴۰۵**: داده سال جاری فقط تا آخرین ماه موجود است. باید فیلد `is_partial` یا `months_available` در سطح سال ذخیره شود تا تحلیل‌ها بتوانند این موضوع را لحاظ کنند.

## ملاحظات فنی

### محدودیت‌های رایج در سایت‌های دولتی ایران
1. **Captchas**: ممکن است نیاز به حل دستی یا سرویس OCR باشد.
2. **Rate limiting**: تأخیر حداقل ۲ ثانیه بین درخواست‌ها ضروری است.
3. **Session**: کوکی‌ها ممکن است پس از چند دقیقه منقضی شوند.
4. **Pagination**: داده‌ها معمولاً در صفحات ۵۰ یا ۱۰۰ رکوردی ارائه می‌شوند.
5. **Encoding**: حتماً UTF-8 بررسی شود، گاهی Windows-1256 برای عربی/فارسی استفاده می‌شود.
6. **فیلتر داخلی**: اگر از داخل ایران دسترسی نداریم، از پروکسی استفاده شود.

### استراتژی ذخیره‌سازی
- **اصل immutability**: داده خام دقیقاً همان چیزی که از سایت دریافت می‌شود ذخیره شود (HTML/JSON).
- هیچ پردازشی روی داده خام انجام نمی‌شود. پردازش در `05-Data/interim/` و `05-Data/processed/`.
- هر scrape با timestamp و snapshot کامل ذخیره شود.
